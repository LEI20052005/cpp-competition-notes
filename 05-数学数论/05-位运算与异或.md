# 位运算与异或

## 按位与 &

**规则**：两个二进制位同时为 1 时，结果为 1，否则为 0

**竞赛中常见用法**：
- 判断奇偶：`n & 1`，结果为 1 是奇数，为 0 是偶数（比 n%2 更快）
- 提取特定位：比如取数字的第 k 位：`(n >> k) & 1`
- 清零特定位：比如把 n 的第 k 位清零：`n & ~(1 << k)`
- 判断两个数字的可达性是否有交集

## 按位或 |

**规则**：两个二进制位只要有一个为 1，结果为 1，否则为 0

**竞赛中常见用法**：
- 置位（把特定位设为 1）：比如把 n 的第 k 位设为 1：`n | (1 << k)`
- 合并多个状态：把数字的所有可达状态合并到一个整数里，用一个位表示一个数字是否可达（0-9 共 10 位，用一个 int 就够了）
- 状态更新：比如 Floyd 算法中更新可达矩阵时，`reach[i] |= reach[j]` 表示把 i 能到的所有状态，加上 j 能到的状态

## 按位非 ~

**规则**：对二进制位取反，0 变 1，1 变 0（注意 C++ 中是对补码取反）

- 配合 & 实现清零特定位：比如 `n & ~(1 << k)`，把第 k 位清零
- **注意**：~ 是单目运算符，优先级比 & / | 高，写代码时要注意括号

## 按位异或 ^

**规则**：相同为 0，不同为 1

**竞赛中常见用法**：
- 翻转特定位：比如把 n 的第 k 位翻转：`n ^ (1 << k)`
- 交换变量（不借助中间变量）：`a ^= b; b ^= a; a ^= b;`
- 找数组中唯一出现一次的数：所有数异或，结果就是那个唯一的数
- 判断两数是否相等：`a ^ b == 0` 表示 a 和 b 相等
- 性质：`a[i] ^ a[j] = x ⇒ a[j] = a[i] ^ x`

## 移位运算符 << / >>

- 左移 `<<`：把二进制位向左移动，右边补 0，等价于乘以 2 的幂
  - `n << k` 等价于 `n * (2^k)`（不溢出时）
- 右移 `>>`：把二进制位向右移动，正数左边补 0，负数补符号位，等价于除以 2 的幂（向下取整）
  - `n >> k` 等价于 `n / (2^k)`（正数时）

### 易错点

```cpp
int t = ans | (1 << i);
// 1 << i 才是第 i 位变成 1
// i << 1 是把 i 乘 2，完全不是一回事
```

## 异或：前缀异或 + 滑动窗口（完整思路代码）

### 预处理前缀和、前缀异或（基础操作，必学）

```cpp
sum[0] = 0;
xor_sum[0] = 0;
for (int i = 1; i <= n; ++i) {
    cin >> a[i];
    sum[i] = sum[i-1] + a[i];
    xor_sum[i] = xor_sum[i-1] ^ a[i];
}
```

### 区间异或

- 区间 [l, r] 的异或和 = `xor_sum[r] ^ xor_sum[l-1]`（异或逆运算仍是异或）

### 排序 pair 为滑动窗口做准备

```cpp
typedef pair<long long, int> PLI;
vector<PLI> all_points;   // (坐标值，靶子编号)

// 将(坐标值，靶子编号)加入vector
// emplace_back比push_back更高效，直接构造pair
all_points.emplace_back(x, i);

// sort默认对pair按first升序、second升序排序，正好符合我们的需求
// 排序后，所有坐标从小到大排列，为滑动窗口做准备
sort(all_points.begin(), all_points.end());
```

// mask |= ... : 把这一位标记为 1（代表这个数字出现过）
