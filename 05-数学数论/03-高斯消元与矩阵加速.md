## 矩阵乘法规则

- 矩阵 A × 矩阵 B = 新矩阵 C
- $C[i][j] = A$ 的第 $i$ 行 $\cdot$ $B$ 的第 $j$ 列

## 斐波那契递推式转化为矩阵乘法（矩阵加速）

核心步骤，也是矩阵加速的关键！把 f(n) = f(n-1) + f(n-2) 写成矩阵相乘的形式：

### 1. 先写基础等式

```
f(n)   = 1*f(n-1) + 1*f(n-2)
f(n-1) = 1*f(n-1) + 0*f(n-2)
```

> 第二个等式是「凑数」的，目的是把递推式转化为矩阵形式

### 2. 转化为矩阵乘法

$$\begin{bmatrix} f(n) \\ f(n-1) \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix} \times \begin{bmatrix} f(n-1) \\ f(n-2) \end{bmatrix}$$

### 3. 递推展开（关键！）

$$\begin{bmatrix} f(n) \\ f(n-1) \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-2} \times \begin{bmatrix} f(2) \\ f(1) \end{bmatrix}$$

- 右边的 [f(2), f(1)] 是初始值（[1,1]）
- 中间的矩阵就是我们要算幂的「转移矩阵」（记为 A）
- 算 A^(n-2)，再乘以初始值矩阵，就能直接得到 f(n)！

## 参考：矩阵快速幂模板（补充）

```cpp
struct Mat {
    ll a[2][2];
    Mat() { memset(a, 0, sizeof a); }
    Mat operator*(const Mat &o) const {
        Mat r;
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                for (int k = 0; k < 2; k++)
                    r.a[i][j] = (r.a[i][j] + a[i][k] * o.a[k][j]) % MOD;
        return r;
    }
};

Mat qpow(Mat base, ll n) {
    Mat res; res.a[0][0] = res.a[1][1] = 1; // 单位矩阵
    while (n) {
        if (n & 1) res = res * base;
        base = base * base;
        n >>= 1;
    }
    return res;
}

ll fib(ll n) {
    if (n <= 2) return 1;
    Mat base;                 // 转移矩阵 A = [[1,1],[1,0]]
    base.a[0][0] = 1; base.a[0][1] = 1;
    base.a[1][0] = 1; base.a[1][1] = 0;
    Mat A = qpow(base, n - 2);
    return (A.a[0][0] + A.a[0][1]) % MOD; // × [f(2), f(1)] = [1,1]
}
```
