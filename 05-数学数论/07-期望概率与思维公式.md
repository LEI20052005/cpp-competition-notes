## 不同集合匹配最小次数

- 有若干组集合，每组内部有若干元素。
- **规则**：每次配对，必须从两个不同集合各取 1 个元素互相抵消，不允许同一个集合内部两个元素配对。
- **问题**：求最少配对次数，把全部元素处理完。

**核心公式**：
- S：全部元素总数量
- M：所有集合中最大那一个集合的元素个数

$$ans = \max(M, \lceil S/2 \rceil)$$

```cpp
ans = max(1LL * max_val, (sum + 1) / 2);
```

## 直线穿过网格中心点（=》三角形）

- 任意直线 $y = \frac{b}{a}x$ 穿过多少个网格正方形中心点
- 当且仅当 aa, bb 同时奇数：线段上一共有 g 个中心点。(gcd(aa,bb)==1), g = gcd(a,b)
- 否则：0 个中心点
- 三角形镜像补矩形，公式 (Ans=(ab+t)/2)。先除 gcd 看互质；互质两数都奇数，t 取 gcd，否则 t 为 0。

## 期望：三种随机模型（必背）

1. **选中就删，永不重试** → 调和数 $H_n = 1 + 1/2 + \ldots + 1/n$
2. **永远不删，无限随机选** → 概率 p = 1/n
3. **失败留着、成功才删** → 几何分布：(1-p)/p

### 几何分布 vs 调和数模型对比表

| 对比项 | 本题（几何分布 q/p） | 调和数模型（Hₙ） |
|---|---|---|
| 题目状态 | 失败保留，成功才移除，可反复选中 | 选中即移除，只会被选一次 |
| 核心行为 | 一题反复提交，直到成功 | 随机挑选，不重复选取 |
| 考察目标 | 失败次数、罚时期望 | 元素被选中的次数期望 |
| 典型公式 | $\sum \frac{1-p_i}{p_i}$ | $H_n = \sum_{k=1}^n \frac{1}{k}$ |

## Short 类型（配合 DP 使用）

- 取值范围：[-32768, 32767]，适合答案 / DP 权值不超 3e4 的题目，超限必须换 int。
- 运算规则：short 参与四则运算时自动提升为 int，short + int → int，赋值回 short 自动截断。
- `memset(dp, 0xc0, sizeof(dp));` // 全初始化为负无穷（short DP 标配）
