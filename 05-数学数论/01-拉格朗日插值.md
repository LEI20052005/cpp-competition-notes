# 拉格朗日插值

## 用途

给定 m 个点 (x₀,y₀), (x₁,y₁), …, (xₘ₋₁,yₘ₋₁)，唯一确定一个次数不超过 m−1 的多项式 F(x)。求 F(t) mod MOD。

## 特点

- x 可以是任意不相同的数，不要求连续
- 复杂度 O(m²)
- 适合 m ≤ 1000
- 模必须是质数，用费马小定理求逆元

## 模板

```cpp
typedef long long ll;
const int MOD = 998244353;   // 模数，必须是质数

// 快速幂（费马小定理求逆元用）
ll qpow(ll a, ll b) {
    ll res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

/**
 * @brief 朴素拉格朗日插值，任意横坐标点
 * @param pts vector<pair<ll,ll>> 存储已知点集合，每个pair:{x,y}=F(x)
 *           所有x必须互不相同！
 * @param t 要求 F(t) 的自变量 t
 * @return ll F(t) mod MOD
 */
ll lagrange(vector<pair<ll, ll>>& pts, ll t) {
    int m = pts.size();   // 点的总数量；多项式最高次数 ≤ m-1
    ll ans = 0;           // 存储最终求和结果，初始0

    // 外层循环：遍历求和公式每一项 i
    for (int i = 0; i < m; i++) {
        ll xi = pts[i].first;   // 当前点横坐标 x_i
        ll yi = pts[i].second;  // 当前点纵坐标 y_i = F(x_i)

        ll numer = 1;   // 分子：∏_{j≠i} (t - x_j)
        ll denom = 1;   // 分母：∏_{j≠i} (x_i - x_j)

        // 内层循环：累乘分子分母，j != i
        for (int j = 0; j < m; j++) {
            if (i == j) continue;   // j等于i跳过，公式要求 j≠i

            ll xj = pts[j].first;
            // 计算分子因子 (t-xj)，减法后转成模下非负数
            numer = numer * ((t - xj) % MOD + MOD) % MOD;
            // 计算分母因子 (xi-xj)，减法后转成模下非负数
            denom = denom * ((xi - xj) % MOD + MOD) % MOD;
        }

        ll inv_denom = qpow(denom, MOD - 2); // 分母的模逆元，费马小定理

        // term = yi * numer / denom mod MOD
        ll term = yi * numer % MOD;
        term = term * inv_denom % MOD;

        ans = (ans + term) % MOD; // 将该项累加到答案
    }
    return ans;
}
```
