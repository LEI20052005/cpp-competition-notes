# 线性同余方程 + 扩展欧几里得

## 一、核心知识点总纲

### 1. 线性同余方程标准形式

$$a \cdot x \equiv b \pmod{m}$$

含义：$a \cdot x - b$ 能被 $m$ 整除，求整数 $x$ 的最小非负整数解。

### 2. 有解充要条件

设 $d = \gcd(a,m)$

方程有整数解 当且仅当：$d \mid b$，也就是 $b \bmod d = 0$；不满足 → 无解。

## 二、通解公式

若求出一个特解 $x_0$，所有解：

$$x = x_0 + t \cdot \frac{m}{d}, \quad t \in \mathbb{Z}$$

最小非负解：对 $\frac{m}{d}$ 取模转正即可。

## 三、两大必备模板函数（带逐行详细注释）

### 模板1：扩展欧几里得 exgcd

作用：求不定方程 $ax + by = gcd(a,b)$ 的一组整数解 (x,y)，返回最大公约数。

```cpp
// 扩展欧几里得：求 ax + by = gcd(a,b) 的一组整数解 (x, y)
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1; y = 0;   // gcd(a,0)=a，a*1+0*0=a
        return a;
    }
    ll g = exgcd(b, a % b, y, x); // 交换 x,y：递归回溯时自动换位
    y -= a / b * x;               // 回代修正
    return g;
}
```

### 模板2：通用解线性同余方程

功能：解方程 $ax \equiv b \pmod{m}$；返回：最小非负解；无解返回 -1。

```cpp
// 解 ax ≡ b (mod m)，返回最小非负解；无解返回 -1
ll solve_congruence(ll a, ll b, ll m) {
    ll x, y;
    ll d = exgcd(a, m, x, y);
    if (b % d != 0) return -1;          // 无解：d 不整除 b
    ll x0 = x * (b / d) % m;            // 特解
    x0 = (x0 % (m / d) + (m / d)) % (m / d); // 转成最小非负解（对 m/d 取模）
    return x0;
}
```

## 四、裴蜀（Bézout）定理

- **裴蜀定理**：如果 a,b 均为整数，则有整数 x 和 y，使得 ax+by=gcd(a,b)。
- **推论**：整数 a 与 b 互素 当且仅当 存在整数 x 和 y 使 ax+by=1。
- 对任意 x 和 y，d = ax+by，d 一定是 gcd(a,b) 的整数倍；最小的 d 是 gcd(a,b)。

## 五、同余与阶（数论杂项）

通用推导规则永远成立：

设：10 模 m 的阶为 d

1. $10^d \equiv 1 \pmod{m}$
2. d 个相同数字 x 组成的数：$\underbrace{xx\cdots x}_{d个} = x \cdot \frac{10^d - 1}{9}$，必然满足 $\equiv 0 \pmod{m}$

示例：阶 = 816 ⇒ 10 的 816 次方模 2023 = 1；816 个相同数字 ⇒ 模 2023 = 0

## exgcd 完整模板

```cpp
ll exgcd(ll a, ll b, ll &x, ll &y) 
{
// 递归终点：b=0 时
// 方程变为 a*x + 0*y = a
// 直接赋值特解 x=1, y=0
if (b == 0) 
{
x = 1;
y = 0;
return a;  // 返回 gcd(a,0)=a
}
// 递归求解 gcd(b, a%b)
// 把 y,x 传进去，方便回溯时交换系数
ll d = exgcd(b, a % b, y, x);
// 核心公式：向上一层递推，更新 y
y -= a / b * x;
// 返回 a 和 b 的最大公约数
return d;
}
```

## solve 线性同余方程

```cpp
ll solve(ll a, ll b, ll m)
{
ll x, y;
    // 1. 把 a 变成正数，b 同步变号（保证方程等价）
    if (a < 0) {
        a = -a;
        b = -b;
    }
    // 2. 把 b 变成模 m 下的非负数（永远安全）
    b = (b % m + m) % m;
    // 求 d = gcd(a,m)，同时得到 a*x + m*y = d 的一组解
    ll d = exgcd(a, m, x, y);
    // 有解条件：b 必须是 d 的倍数
    if (b % d != 0)
        return -1;   // 无解
    // 解的步长：所有解间隔 m/d
    ll step = m / d;
    // 把 exgcd 求出的 x 转成 0~step-1 之间的正数
    x = (x % step + step) % step;
    // 特解放大：从 a*x ≡ d 放大到 a*x ≡ b
    x = x * (b / d) % step;
    return x;
}
```
