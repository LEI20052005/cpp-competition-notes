# 欧式筛与博弈

## 欧式筛（线性筛）

- 欧式筛（线性筛）
- `prime[i]` 就是第 i 小的素数

## 参考：欧式筛模板（补充）

```cpp
const int MAXN = 1000010;
int prime[MAXN], cnt = 0;
bool is_comp[MAXN];

void euler_sieve(int n) {
    for (int i = 2; i <= n; i++) {
        if (!is_comp[i]) prime[++cnt] = i;  // prime[i]就是第i小的素数
        for (int j = 1; j <= cnt && i * prime[j] <= n; j++) {
            is_comp[i * prime[j]] = true;
            if (i % prime[j] == 0) break;   // 线性：每个合数只被最小质因子筛一次
        }
    }
}
```

## 博弈题经验总结

1. 很多取物博弈，不要纠结中间全部过程，找「谁拥有最终决定权」，决定权持有者直接选对自己最优的结果。
2. 可取可不用，看最后触碰；多份听全局，单份按序抢；无效改回合，不改变答案。
