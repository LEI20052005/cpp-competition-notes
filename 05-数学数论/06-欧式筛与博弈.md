# 欧式筛与博弈

## 欧式筛（线性筛）

- 欧式筛（线性筛）
- `prime[i]` 就是第 i 小的素数

## 博弈题经验总结

1. 很多取物博弈，不要纠结中间全部过程，找「谁拥有最终决定权」，决定权持有者直接选对自己最优的结果。
2. 可取可不用，看最后触碰；多份听全局，单份按序抢；无效改回合，不改变答案。

## 欧式筛（线性筛）模板

```cpp
// 这是一个 inline 函数，编译器会尝试把它直接嵌入调用处，减少函数调用开销
inline void xxs()
{
    // pd 数组：pd[x] 表示 x 是否为合数（1表示合数，0表示素数）
    // 初始化：pd[1] = 1，因为 1 不是素数
    pd[1] = 1;
    // 外层循环：遍历 2 到 n 的所有整数 i
    for (int i = 2; i <= n; i++)
    {
        // -------------------- 第一步：判断当前 i 是否为素数 
        // 如果 pd[i] == 0，说明 i 从来没被标记过，因此它是一个素数
        if (!pd[i]) 
            // 把这个素数加入 prime 数组中，cnt 是当前已经找到的素数个数
            prime[++cnt] = i;
        // -------------------- 第二步：用当前 i 去标记合数 
        // 内层循环：遍历已经找到的所有素数 prime[j]
        // 终止条件：
        // 1. j <= cnt：不超过已经找到的素数个数
        // 2. prime[j] * i <= n：乘积不超过我们要筛的范围 n，否则不用标记
        for (int j = 1; j <= cnt && prime[j] * i <= n; j++)
        {
            // 标记 prime[j] * i 为合数（因为它是两个数的乘积，肯定不是素数）
            pd[prime[j] * i] = 1;
            // -------------------- 核心优化：break 条件 
            // 如果 i 能被 prime[j] 整除（即 i % prime[j] == 0）
            if (i % prime[j] == 0) 
                break;
            // 为什么这里要 break？
            // 原理：prime[j] 是 i 的最小质因数
            // 再往后乘 prime[j+1]、prime[j+2]... 时，i * prime[k] 的最小质因数会变成 prime[j]，而不是 prime[k]
            // 这样就会导致这个合数被重复标记（后面的 i 再遇到它的最小质因数时又会标记一次）
            // 所以这里 break，保证每个合数只被它的最小质因数标记一次
        }
    }
}
```
