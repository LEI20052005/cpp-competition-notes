# 组合数与逆元

## 组合数定义

> 组合数的定义是：从 x 个元素中选 y 个，不考虑顺序，有多少种选法。

$$C_{x}^{y} = \frac{x!}{y! \cdot (x-y)!}$$

## 排列数定义

> 排列数的定义是：从 x 个元素中选 y 个排成一列，有多少种排法。

$$A_{x}^{y} = \frac{x!}{(x-y)!}$$

## 根据二项式定理

$$(u + v)^k = \sum_{i=0}^k C_k^i \, u^{k-i} v^i$$

## 模意义下的除法

$$\frac{a}{b} \pmod{MOD} = a \times inv(b) \pmod{MOD}$$

> 除以 b = 乘以 b 的逆元

## 组合数取模

原式：$C(x,y) = \frac{x!}{y!\cdot(x-y)!}$

模意义下不能除法，换成乘逆元：

$$C(x,y) \equiv x! \times inv(y!) \times inv((x-y)!) \pmod{MOD}$$

## 预处理组合数模 k

组合数有递推公式：

$$C_i^j = C_{i-1}^{j-1} + C_{i-1}^{j}$$

边界：$C_i^0 = 1,\ C_i^i = 1$

## 逆元

- 0 的阶乘和逆元都为 1

### 求逆元的两大方法

| 方法 | 前提条件 | 时间复杂度 | 适合场景 |
|---|---|---|---|
| 快速幂（费马小定理） | p 是质数 | O(n log p) | 单次求逆元、n 很小 |
| 线性递推 | p 是质数 | O(n) | 批量求逆元、n 很大 |

### 逆元存在的真正限制条件

1. **MOD 必须是质数**（比如你用的 10⁹+7 就是质数）
2. **a 不能是 MOD 的倍数**（否则 a 和 MOD 不互质，逆元不存在）

> 模数 p 必须是质数，且要求我们求逆元的数 i 满足 1 ≤ i < p。

## 参考：组合数预处理 + 逆元代码（补充）

```cpp
const int MOD = 998244353;
const int MAXN = 1000010;
ll fac[MAXN], inv[MAXN];

ll qpow(ll a, ll b) { ... }  // 快速幂

void init() {
    fac[0] = 1;
    for (int i = 1; i < MAXN; i++) fac[i] = fac[i-1] * i % MOD;
    inv[MAXN-1] = qpow(fac[MAXN-1], MOD-2);
    for (int i = MAXN-2; i >= 0; i--) inv[i] = inv[i+1] * (i+1) % MOD;
}

ll C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fac[n] * inv[m] % MOD * inv[n-m] % MOD;
}
```
