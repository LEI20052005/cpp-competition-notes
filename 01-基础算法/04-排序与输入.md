# 排序与输入

## 归并排序求逆序对

```cpp
long long ans = 0;   // 逆序对总数，必须long long，防止溢出
int a[500010], t[500010]; // a原数组，t归并时临时辅助数组

// sort_：对区间[l,r]归并排序，同时统计逆序对
void sort_(int l, int r) {
    if (l >= r) return; // 区间只有1个或没有元素，直接返回
    int m = (l + r) / 2;   // 取中点，分治
    sort_(l, m);      // 递归处理左半区间 [l,m]
    sort_(m + 1, r);  // 递归处理右半区间 [m+1,r]

    int cur = l;   // t数组当前存放位置
    int ll = l;    // 左半部分指针
    int rr = m + 1; // 右半部分指针

    // 双指针合并两个有序子数组
    while (ll <= m && rr <= r) {
        if (a[ll] <= a[rr]) {
            t[cur] = a[ll];
            cur++;
            ll++;
        } else {
            // a[ll] > a[rr]：产生逆序对
            // 左区间 ll~m 的全部元素都比a[rr]大，一共 m-ll+1 个逆序对
            t[cur] = a[rr];
            ans += m - ll + 1;
            rr++;
        }
    }
    // 左半边剩下的直接复制进t
    while (ll <= m) {
        t[cur] = a[ll];
        cur++; ll++;
    }
    // 右半边剩下的直接复制进t
    while (rr <= r) {
        t[cur] = a[rr];
        cur++; rr++;
    }
    // 把合并好的有序区间，拷贝回原数组a
    for (int i = l; i <= r; i++)
        a[i] = t[i];
}

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    sort_(1, n);
    cout << ans;
    return 0;
}
```

## 输入

### cin >> s1 的分隔规则

`cin >> s1` 会以 **空格 / 换行** 作为分隔，所以：

- 第一次读 `s1 = "1"`
- 第二次读 `s1 = "5"`
- 第三次读 `s1 = "2"`

> 根本读不到一整行！需要读整行用 `getline`。
