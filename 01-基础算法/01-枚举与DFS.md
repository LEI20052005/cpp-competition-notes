# 枚举与 DFS

## 枚举

> 枚举 = 把所有可能的情况全部试一遍，找出符合条件的答案

**特点**：不绕弯子、不优化、不找数学规律、全部试一遍

**适合**：情况总数不多（比如 10000 以内）、题目要求所有方案

- 只要总数不大（< 10 万），直接暴力枚举！
- 一般枚举都可以用 `dfs` / `next_permutation`

## DFS 不超时的 4 种情况

1. 数据量小（n ≤ 30）
2. 树 / 图 / 网格（线性遍历）
3. 能大量剪枝（无效路径少）
4. 能记忆化（状态不重复）

## 大图的 DFS 规则

1. 凡是节点数开到 10⁴、10⁵ 的图：
   - **禁止使用递归 DFS 遍历长链**，必栈溢出 + 超时
   - 优先 BFS（队列迭代）或非递归 DFS（手写栈）
2. 无权图最短路 = **BFS 专属场景**，记住这个固定套路即可

## 附：函数传数组的 DFS 副本写法（配合枚举/DFS 使用）

```cpp
void dfs(int cur, bool a[], int wz){
    // 你的原有逻辑（修改a）
    // ...

    // 递归时也传副本
    for(int i = 1; i <= 9; i++){
        bool new_a[10];
        memcpy(new_a, a, sizeof(bool) * 10);
        dfs(cur + 1, new_a, i);
    }
}
```

> 传数组给函数时，记得要 `memcpy` 副本，否则函数里的变动会影响函数外的变动

## 倍增法：跳步问题模板

```cpp
// 1. 常量定义（核心配置）
// MAXN：节点数量上限，题目中n<=1e5，所以设1e5+5避免边界越界
const int MAXN = 1e5 + 5;
// LOG：倍增的最大阶数，2^30 ≈ 10亿，覆盖题目中y<=1e9的所有步数
const int LOG = 30; 
// 2. 核心数组：倍增表
// up[k][i] 表示：从节点i出发，走 2^k 步后到达的节点
// 比如 up[0][i] = 走1步（2^0）的位置，up[1][i] = 走2步（2^1）的位置，up[2][i] = 走4步（2^2）的位置
int up[LOG][MAXN];
int main() {
    // 4. 输入基本参数
    int n, q; // n：节点总数，q：查询次数
    cin >> n >> q;
    // 5. 初始化倍增表的「0阶」（最基础的一步）
    // up[0][i] 是走 2^0 = 1 步的位置，也就是题目给出的a[i]
    for (int i = 1; i <= n; ++i) {
        cin >> up[0][i]; // 直接读入：从i出发走1步到up[0][i]
    }
    // 6. 预处理倍增表（核心！递推计算所有高阶步数）
    // 从1阶到29阶（共30阶），递推计算走 2^k 步的位置
    for (int k = 1; k < LOG; ++k) {
        // 对每个节点i，计算up[k][i]
        for (int i = 1; i <= n; ++i) {
            // 递推公式：走 2^k 步 = 先跳 2^(k-1) 步，再跳 2^(k-1) 步
            // 比如：走4步（2^2）= 先走2步（2^1），再走2步（2^1）
            // 这是倍增法的核心思想：用已有的小步数推导大步数，避免暴力模拟
            up[k][i] = up[k-1][up[k-1][i]];
        }
    }
    // 7. 处理每个查询
    while (q--) {
        int x, y; // x：起点，y：要走的总步数
        cin >> x >> y;
        int cur = x; // cur：当前所在的节点，初始为起点x
        // 8. 把总步数y拆成「2的幂次和」，逐次跳转
        // 比如y=5（二进制101）= 4（2^2） + 1（2^0），只需跳2次（4步+1步），而非5次
        for (int k = 0; k < LOG; ++k) {
            // 检查y的二进制第k位是否为1（表示需要跳2^k步）
            // (1 << k) 是生成2^k的二进制数（比如k=2时是100）
            // y & (1 << k) 非0 → 第k位是1，需要跳这一步
            if (y & (1 << k)) { 
                cur = up[k][cur]; // 跳2^k步，更新当前节点
            }
        }
        // 9. 输出最终位置
        cout << cur << '\n';
    }
    return 0;
}
```
