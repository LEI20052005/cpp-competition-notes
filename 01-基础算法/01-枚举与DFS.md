# 枚举与 DFS

## 枚举

> 枚举 = 把所有可能的情况全部试一遍，找出符合条件的答案

**特点**：不绕弯子、不优化、不找数学规律、全部试一遍

**适合**：情况总数不多（比如 10000 以内）、题目要求所有方案

- 只要总数不大（< 10 万），直接暴力枚举！
- 一般枚举都可以用 `dfs` / `next_permutation`

## DFS 不超时的 4 种情况

1. 数据量小（n ≤ 30）
2. 树 / 图 / 网格（线性遍历）
3. 能大量剪枝（无效路径少）
4. 能记忆化（状态不重复）

## 大图的 DFS 规则

1. 凡是节点数开到 10⁴、10⁵ 的图：
   - **禁止使用递归 DFS 遍历长链**，必栈溢出 + 超时
   - 优先 BFS（队列迭代）或非递归 DFS（手写栈）
2. 无权图最短路 = **BFS 专属场景**，记住这个固定套路即可

## 附：函数传数组的 DFS 副本写法（配合枚举/DFS 使用）

```cpp
void dfs(int cur, bool a[], int wz){
    // 你的原有逻辑（修改a）
    // ...

    // 递归时也传副本
    for(int i = 1; i <= 9; i++){
        bool new_a[10];
        memcpy(new_a, a, sizeof(bool) * 10);
        dfs(cur + 1, new_a, i);
    }
}
```

> 传数组给函数时，记得要 `memcpy` 副本，否则函数里的变动会影响函数外的变动
