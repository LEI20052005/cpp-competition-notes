## Dijkstra（单源最短路）

### 图规模分级（决定用哪种算法）

| 规模 | 点数 / 边数 | 做法 |
|---|---|---|
| 1. 小图 | V ≤ 10³, E ≤ 10⁴ | 朴素算法就行，毫秒级不超时 |
| 2. 中图 | V ≤ 10⁴, E ≤ 10⁵ | 必须堆优化，10~100ms 稳过 |
| 3. 大图 | V ≤ 10⁵, E ≤ 10⁶ | 邻接表 + 堆优化，控制在 100ms~1s 不超时 |
| 4. 超大规模 | V > 10⁶ | 普通算法扛不住，要用并行、分层、A* 这类高级做法 |

> `//上面方法属于大图` —— 即大图用「邻接表 + 堆优化」

### 适用范围

- **图权要求**：所有边权必须 ≥ 0（距离、耗时、费用等）
- **图类型**：有向图 / 无向图、连通 / 非连通均可
- **问题类型**：单源最短路径（1 个起点到所有终点）
- **不适用**：含负权边、负权环（改用 Bellman-Ford 或 SPFA）

## Dijkstra 完整模板（堆优化）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;
// pair<距离, 点编号>
typedef pair<int, int> pii;
const int N = 200010;
const int INF = 0x3f3f3f3f;
vector<pii> g[N];  // g[u] = {v, w}
int dis[N];        // 存起点到每个点的最短路
void dijkstra(int s)
{
    // 全部距离初始化为无穷大
    memset(dis, 0x3f, sizeof(dis));
    // 小根堆：距离小优先
    priority_queue<pii, vector<pii>, greater<pii>> q;
    dis[s] = 0;        // 起点到自己距离为0
    q.push({0, s});    // 起点入堆
    while (!q.empty())
    {
        // 取出当前距离最小的点
        auto [d, u] = q.top();
        q.pop();
        // 核心：只有距离更大的过期数据才跳过
        if (d > dis[u])
            continue;
        // d == dis[u] 合法，正常走
        // 遍历 u 所有相连的边
        for (auto [v, w] : g[u])
        {
            // 松弛：走 u 更近就更新
            if (dis[v] > dis[u] + w)
            {
                dis[v] = dis[u] + w;
                q.push({dis[v], v});
            }
        }
    }
}
```

## 差分数组

```cpp
//差分数组
bool isok(int x)
{
    // 1. 把差分数组全部清零
    // 每次判断都要重新算，所以必须清空
    memset(diff,0,sizeof(diff));
    // 2. 把前 x 个操作，全部用【差分】记录下来
    // 这里不是真的去减数组，只是“标记”要减哪里、减多少
    for(int i=1;i<=x;i++)
    {
        // 第 i 个操作：在区间 [l[i], r[i]] 减去 d[i]
        // 差分技巧：区间减法只需要改两个点！O(1) 完成
        diff[l[i]] += d[i];     // 区间起点：加上要减的数
        diff[r[i]+1] -= d[i];   // 区间终点+1：减去要减的数
    }
    // 3. 计算前缀和 → 还原出每个位置 一共被减了多少
    for(int i=1;i<=n;i++)
    {
        // need[i] = 前i个差分的和
        // 意思是：第i个位置，前x个操作一共要减掉多少
        need[i] = need[i-1] + diff[i];
        // 4. 关键判断：
        // 如果这个位置一共要减掉的数量 > 原本有的数量
        // 说明不够减！操作失败！
        if(need[i] > rest[i])
            return 0; // 返回false，表示前x个操作不行
    }
    // 5. 所有位置都够减，返回true，表示前x个操作完全没问题
    return 1;
}
```

## 二维前缀和模板

```cpp
// pre[i][j]：二维前缀和数组
// 含义：左上角坐标(1,1) 到右下角坐标(i,j) 围成矩形内所有元素总和
ll pre[MAXN][MAXN];
/**
 * @brief 二维前缀和查询函数
 * 参数 x1,y1：查询矩形左上角
 * 参数 x2,y2：查询矩形右下角
 * 返回值：矩形 [x1,y1] ~ [x2,y2] 所有数字之和
 * 容斥原理：大矩形 - 上方区域 - 左侧区域 + 重复减掉的左上角区域
 */
inline ll get(int x1,int y1,int x2,int y2){
    return pre[x2][y2]          // (1,1)~(x2,y2) 整块大矩形
         - pre[x1-1][y2]        // 减去矩形上方多余部分 (1,1)~(x1-1,y2)
         - pre[x2][y1-1]        // 减去矩形左侧多余部分 (1,1)~(x2,y1-1)
         + pre[x1-1][y1-1];     // 左上角区域被连续减2次，补偿加回来一次
}
// 预处理构建二维前缀和，下标从1开始遍历矩阵
for(int i=1;i<=n;i++){
    for(int j=1;j<=n;j++){
        cin>>val;  // 读取当前位置(i,j)原始数值
        // 前缀和递推公式
        // pre[i-1][j] = 当前格子上方前缀和
        // pre[i][j-1] = 当前格子左方前缀和
        // pre[i-1][j-1] = 左上角区域，上方+左方重复计算了一次，需要减掉
        pre[i][j] = val + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1];
    }
}
```
