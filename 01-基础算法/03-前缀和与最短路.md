## Dijkstra（单源最短路）

### 图规模分级（决定用哪种算法）

| 规模 | 点数 / 边数 | 做法 |
|---|---|---|
| 1. 小图 | V ≤ 10³, E ≤ 10⁴ | 朴素算法就行，毫秒级不超时 |
| 2. 中图 | V ≤ 10⁴, E ≤ 10⁵ | 必须堆优化，10~100ms 稳过 |
| 3. 大图 | V ≤ 10⁵, E ≤ 10⁶ | 邻接表 + 堆优化，控制在 100ms~1s 不超时 |
| 4. 超大规模 | V > 10⁶ | 普通算法扛不住，要用并行、分层、A* 这类高级做法 |

> `//上面方法属于大图` —— 即大图用「邻接表 + 堆优化」

### 适用范围

- **图权要求**：所有边权必须 ≥ 0（距离、耗时、费用等）
- **图类型**：有向图 / 无向图、连通 / 非连通均可
- **问题类型**：单源最短路径（1 个起点到所有终点）
- **不适用**：含负权边、负权环（改用 Bellman-Ford 或 SPFA）

### 参考：堆优化 Dijkstra 模板（补充）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 100010;
const ll INF = 1e18;

struct Edge { int to, w; };
vector<Edge> g[MAXN];
ll dist[MAXN];
bool vis[MAXN];

void dijkstra(int s) {
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<pair<ll,int>>> q;
    fill(dist, dist + MAXN, INF);
    dist[s] = 0;
    q.push({0, s});
    while (!q.empty()) {
        auto [d, u] = q.top(); q.pop();
        if (vis[u]) continue;
        vis[u] = true;
        for (auto &e : g[u]) {
            if (dist[e.to] > dist[u] + e.w) {
                dist[e.to] = dist[u] + e.w;
                q.push({dist[e.to], e.to});
            }
        }
    }
}
```
