## 数组位置：为什么数组要放全局？

- 如果数组放在 main 函数里面，就会因为开空间太大，导致主函数无东西输出。
- 全局区 / 静态区空间大，main 函数内是栈空间，大数组会爆栈。

## 为什么 memset 不适合给 int 数组赋值？

memset 的设计初衷是**按字节操作内存**，比如：

- 把字符数组 (char[]) 全部清 0：`memset(arr, 0, sizeof(arr))`
- 把内存块全部设为 -1：`memset(arr, -1, sizeof(arr))`（因为 -1 的补码是全 1，每个字节都是 0xFF）

但对于 **int、long long 等多字节类型**：

- 只有当你要赋值 **0 或 -1** 时，memset 才是安全的（因为这两个数的所有字节都相同）
- 其他任何值（比如 6、100、100010），用 memset 都是错误的，因为每个字节被单独赋值，最终的 int 值完全不是你想要的

## 正确做法（long long 专用）：循环初始化（最稳、推荐）

```cpp
typedef long long ll;
const ll INF = 1e18;

// 最大值数组 初始为极小
for (int i = 1; i <= maxn; i++)
    for (int j = 1; j <= maxn; j++)
        dp1[i][j] = -INF;

// 最小值数组 初始为极大
for (int i = 1; i <= maxn; i++)
    for (int j = 1; j <= maxn; j++)
        dp2[i][j] = INF;
```

> 补充：`memset(dp, 0xc0, sizeof(dp))` // 全初始化为负无穷（short DP 标配）

## 数组维度限制

| 维度 | 限制 |
|---|---|
| 一维 | size ≤ 1e6 |
| 二维 | a × b ≤ 1e6 |
| 三维 | a × b × c ≤ 1e6 |
| 四维 | a×b×c×d ≤ 1e6 |

> 超过 1e6 就开始危险，超过 4e6 基本必炸！

## 类型存储上限

- int 全局：总数上限 ≈ 6 × 10⁷
- short 全局：总数上限 ≈ 1.3～2.7 × 10⁸（看 OJ 是 256MB / 512MB）

## short 类型

- 取值范围：[-32768, 32767]，适合答案 / DP 权值不超 3e4 的题目，超限必须换 int。
- 运算规则：short 参与四则运算时自动提升为 int，short + int → int，赋值回 short 自动截断。
