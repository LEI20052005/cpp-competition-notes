# 输入与函数

## cin >> s1 的分隔规则

`cin >> s1` 会以 **空格 / 换行** 作为分隔，所以：

- 第一次读 `s1 = "1"`
- 第二次读 `s1 = "5"`
- 第三次读 `s1 = "2"`

> 根本读不到一整行！需要读整行用 `getline`。

## 函数传数组问题

- 传数组给函数时，记得要 `memcpy` 副本，否则函数里的变动会影响函数外的变动。

```cpp
void dfs(int cur, bool a[], int wz){
    // 你的原有逻辑（修改a）
    // ...

    // 递归时也传副本
    for(int i = 1; i <= 9; i++){
        bool new_a[10];
        memcpy(new_a, a, sizeof(bool) * 10);
        dfs(cur + 1, new_a, i);
    }
}
```
