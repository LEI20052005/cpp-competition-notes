# 宏与编译技巧

## 自定义 max / min 宏（配合 short DP）

1. `std::max` 是模板函数：两个参数必须类型完全一致，short 和 int 混用直接编译报错；
2. 自定义三目宏无类型检查，是 short DP 标配：

```cpp
// 必须全括号，防运算优先级BUG
#define max(a,b) ((a)>(b)?(a):(b))
#define min(a,b) ((a)<(b)?(a):(b))
```
