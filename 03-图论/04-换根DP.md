# 换根 DP

## 一、题目模型

- 树上求：所有点到某点的 **权值 × 距离** 总和最大
- 解法：**两次 DFS 换根 DP**

## 二、必须死记的 3 个定义

1. `s1[u]`：以 u 为根的子树权值总和
   - = 自己 + 所有子树
   - 和距离无关，纯求和
2. `s2[u]`：以 u 为根时，全树的加权距离和（答案）
3. `wai`：当前节点「外面」所有点的权值和
   - ❌ 绝对不是父亲一个点
   - ✅ 是父亲头顶一整片 + 父亲其他子树

## 三、你最容易错的 2 个核心公式（背下来）

### 1. dfs1 子树更新公式（永远不变）

```cpp
s1[u] += s1[v];
s2[u] += s1[v] + s2[v];
```

含义：子节点往上走一步，所有点距离 +1，总代价 += 子树权值和

### 2. dfs2 换根公式（你这次错的就是它）

```cpp
s2[v] = s2[cur] - s1[v] + (wai + s1[cur] - s1[v]);
```

拆解（必须理解）：
- `s2[cur]`：原来的答案
- `- s1[v]`：v 子树里所有点距离 -1
- `+ (wai + s1[cur] - s1[v])`：外面所有点距离 +1

### 3. dfs2 递归传递 wai（你第二个错误）

```cpp
dfs2(v, cur, wai + s1[cur] - s1[v]);
```

## 四、「外面」的理解（配图）

```
【外面一切点】wai
        |
       爸爸 u
      / | \
  子树A 子树B 儿子v
```

- 当我们从爸爸 → 儿子：
  - **儿子的外面 = 外面 + 爸爸 + 子树 A + 子树 B**
  - 这一坨总和 = `wai + s1[cur] - s1[v]`
- **正确理解**：新的外面 = 原来的外面 + 父亲这一整块（去掉 v 子树）
