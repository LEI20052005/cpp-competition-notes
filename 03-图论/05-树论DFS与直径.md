# 树论 DFS 与直径

## 两次 dfs 求树的直径

> 两次 dfs 就能求到树的直径：
> 第一次从任意点出发 dfs 找到最远点 u，第二次从 u 出发 dfs 找到最远点 v，u-v 即直径。

## 大图的 DFS 规则

1. 凡是节点数开到 10⁴、10⁵ 的图：
   - **禁止使用递归 DFS 遍历长链**，必栈溢出 + 超时
   - 优先 BFS（队列迭代）或非递归 DFS（手写栈）
2. 无权图最短路 = **BFS 专属场景**，记住这个固定套路即可

## DFS 不超时的 4 种情况

1. 数据量小（n ≤ 30）
2. 树 / 图 / 网格（线性遍历）
3. 能大量剪枝（无效路径少）
4. 能记忆化（状态不重复）
