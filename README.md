# cpp-competition-notes

> C++ 算法竞赛笔记与代码模板，蓝桥杯 / ACM 训练所用代码，包含基础算法、数据结构、图论、动态规划、数论等方向的算法模板与解题笔记。

## 📂 目录结构

```
├── 01-基础算法/          # 枚举、DFS、快速幂、高精度、前缀和、Dijkstra、排序输入
├── 02-数据结构/          # 树状数组、线段树、单调栈/队列、莫队、Bitset
├── 03-图论/              # 链式前向星、基环树、Kruskal 重构树、换根 DP
├── 04-动态规划/          # 数位 DP、背包（含负体积）、DP 经验技巧
├── 05-数学数论/          # 拉格朗日插值、组合数逆元、高斯消元、线性同余、位运算、期望概率
├── 06-字符串/            # 字符串哈希、substr
├── 07-STL与技巧/         # STL 容器、数组内存、输入函数、宏与编译技巧
```
