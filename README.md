# cpp-competition-notes

> C++ 算法竞赛笔记与代码模板，蓝桥杯 / ACM 训练所用代码，包含基础算法、数据结构、图论、动态规划、数论等方向的算法模板与解题笔记。

## 📂 目录结构

```
├── 01-基础算法.md      # 枚举、DFS、倍增、快速幂、高精度、前缀和、Dijkstra 等
├── 02-数据结构.md      # 树状数组、线段树、单调栈/队列、莫队、Bitset、并查集等
├── 03-图论.md          # 链式前向星、基环树、Kruskal 重构树、换根 DP
├── 04-动态规划.md      # 数位 DP、背包（含负体积）、区间 DP
├── 05-数学数论.md      # 拉格朗日插值、线性筛、组合数与逆元、高斯消元、位运算、扩展欧几里得
├── 06-字符串.md        # 字符串哈希、字符串处理技巧
├── 07-STL与技巧.md     # STL 用法、函数传参、memset、类型定义、易错点与解题思路
└── images/             # 笔记中的示意图与题目截图
```

## 📖 项目介绍

本仓库存放竞赛备赛期间手写的 C++ 算法模板与刷题笔记，每段代码附带详细中文注释，记录算法原理、边界条件与易错点。用于巩固 C++ 底层、数据结构与算法能力，适合 C++ 岗位面试复盘。

## 🛠 技术栈

- Language：C++11 / C++17
- 算法方向：数据结构、图论、动态规划、数论、字符串

## ✨ 面试亮点

1. 所有代码为手写实现，不直接复制网上成品，附带个人思路笔记；
2. 覆盖竞赛高频考点，体现 C++ 编码能力、逻辑思维、问题调试能力；
3. 分类整理，方便快速查阅，适合面试快速复盘。
