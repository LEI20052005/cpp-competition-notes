# DP 经验与技巧

## 7. 含负数乘法 → 最大最小双 dp 数组

- 含负数乘法时，同时维护最大值数组和最小值数组（乘负数会翻转大小）。

## 8. 区间 DP 顺序：长度 → 左端点 → 分割点

- 先枚举区间长度，再枚举左端点，最后枚举分割点。

## 9. 关于取模运算

- 后缀是接在中间串右侧，只会影响后缀自身数位权重，**不会改变中间串整体的左移倍数**，因此初始值不用后缀位数计算。

## len[i] == 0x3f3f3f3f 与 long long 初始化

> 正确做法（long long 专用）：方式1 = 循环初始化（最稳、推荐）

```cpp
typedef long long ll;
const ll INF = 1e18;

// 最大值数组 初始为极小
for (int i = 1; i <= maxn; i++)
    for (int j = 1; j <= maxn; j++)
        dp1[i][j] = -INF;

// 最小值数组 初始为极大
for (int i = 1; i <= maxn; i++)
    for (int j = 1; j <= maxn; j++)
        dp2[i][j] = INF;
```

> 注意：`memset` 对多字节类型（int/long long）只有赋 0 或 -1 才安全，其他值（如 0x3f）按字节赋值是错的。所以 long long 数组用循环初始化最稳。

## 循环是小于 1e8

- 循环规模控制在 1e8 以内才安全。
