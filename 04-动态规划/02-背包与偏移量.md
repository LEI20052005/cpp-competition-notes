# 背包与偏移量

## 背包

- 背包（0/1 背包、完全背包等经典模型）

## 重量可为负数的背包

> 体积可能出现负数时，用「偏移量」把下标平移到非负区间。

```cpp
// 假设最大体积差的绝对值不超过 100000，数组开到 200000 以上
const int OFFSET = 100000;
const int MAX_V = 200005;
int dp[110][MAX_V];

int main() {
    // 1. 初始化为极小值，屏蔽所有非法状态
    memset(dp, -0x3f, sizeof(dp));

    // 2. 设定唯一的初始合法起点：0 个物品，实际体积为 0（平移后下标为 OFFSET），价值为 0
    dp[0][OFFSET] = 0;

    for (int i = 1; i <= n; i++) {
        int w = a[i] - k * b[i]; // 当前物品的实际体积（可能为负）
        int v = a[i];            // 当前物品的实际价值
        for (int j = 0; j < MAX_V; j++) {
            // 情况一：不选当前物品，直接继承上一层
            dp[i][j] = dp[i - 1][j];
            // 情况二：选当前物品。必须确保依赖的上一层状态下标未越界
            if (j - w >= 0 && j - w < MAX_V) {
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w] + v);
            }
        }
    }

    // 3. 最终提取答案：前 n 个物品中，总体积恰好为 0（即下标为 OFFSET）时的最大价值
    int ans = dp[n][OFFSET];
    return 0;
}
```
