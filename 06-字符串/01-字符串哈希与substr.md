## substr 截取函数

在 C++ 的 string 里，`s.substr(0, ins)` 是字符串截取函数，**核心作用**：从字符串 s 的第 0 个位置（开头）开始，截取长度为 ins 的子字符串。

**极简解析**：

1. **参数含义**
   - 第一个参数 0：起始下标（字符串下标从 0 开始）
   - 第二个参数 ins：要截取的字符个数
2. **示例**
   - 若 s = "12345678", ins = 3
   - `s.substr(0,3)` → 截取开头 3 个字符 → "123"

## 字符串哈希：双哈希模板

```cpp
// 数组最大长度：题目字符串长度上限 1e6+10，足够用
const int MAXN = 1e6 + 10;
// ===================== 哈希核心参数（竞赛最稳组合）
// 双基数（相当于两种不同的进制）：131、13331 是经验最优值
const ll B1 = 131, B2 = 13331;
// 双模数（两个超大质数）：1e9+7、1e9+9，同时用两个几乎不可能哈希冲突
const ll MOD1 = 1000000007;
const ll MOD2 = 1000000009;
// ===================== 全局数组 =====================
// h1[i]：字符串前 i 个字符，用 基数1+模数1 计算的哈希值
// h2[i]：字符串前 i 个字符，用 基数2+模数2 计算的哈希值
ll h1[MAXN], h2[MAXN];
// p1[i]：预处理 B1^i % MOD1 的结果（快速计算子串哈希）
// p2[i]：预处理 B2^i % MOD2 的结果
ll p1[MAXN], p2[MAXN];
// ===================== 核心函数：获取子串 [l, r] 的哈希值 =====================
// 输入：l, r 是字符串的 1 开始下标
// 输出：一对哈希值（两个模数计算的结果，同时相等才判定子串相等）
pair<ll, ll> get(int l, int r) {
    // 计算子串长度
    int len = r - l + 1;
    // 计算第一个哈希值：
    // h1[r] - h1[l-1] * p1[len]  → 这是字符串哈希公式
    // + MOD1 再 % MOD1 → 防止计算结果为负数（必须加！）
    ll x1 = (h1[r] - h1[l-1] * p1[len] % MOD1 + MOD1) % MOD1;
    // 计算第二个哈希值（同上，换模数和基数）
    ll x2 = (h2[r] - h2[l-1] * p2[len] % MOD2 + MOD2) % MOD2;
    // 返回双哈希结果
    return {x1, x2};
}
// ===================== 主函数 =====================
int main() {
    // n：字符串长度  q：查询次数
    int n, q;
    cin >> n >> q;
    // 输入字符串
    string s;
    cin >> s;
    // ===================== 初始化预处理 =====================
    // 任何数的 0 次方都等于 1
    p1[0] = p2[0] = 1;
    // 循环计算：前缀哈希 + 幂次数组
    for (int i = 1; i <= n; ++i) {
        // 计算 B1^i % MOD1
        p1[i] = p1[i-1] * B1 % MOD1;
        // 计算 B2^i % MOD2
        p2[i] = p2[i-1] * B2 % MOD2;
        // 核心递推公式：
        // 当前哈希 = 前一位哈希 * 基数 + 当前字符ASCII码
        // s[i-1]：因为字符串是 0 开始，哈希数组是 1 开始
        h1[i] = (h1[i-1] * B1 + s[i-1]) % MOD1;
        h2[i] = (h2[i-1] * B2 + s[i-1]) % MOD2;
    }
    // ===================== 处理查询 =====================
    while (q--) {
        // 查询：比较 [a,b] 和 [c,d] 两个子串是否相等
        int a, b, c, d;
        cin >> a >> b >> c >> d;
        // 第一步：长度不同 → 直接输出 No（必须判断！）
        if (b - a != d - c) {
            cout << "No\n";
            continue;
        }
        // 第二步：双哈希值完全相等 → 子串相等
        if (get(a, b) == get(c, d))
            cout << "Yes\n";
        else
            cout << "No\n";
    }
    return 0;
}
```
