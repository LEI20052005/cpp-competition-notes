# 莫队

> 莫队 = 专门用来处理 大量区间询问 的暴力优化算法

## 一、莫队能干什么（经典题型，全覆盖）

1. **统计类（最常用）**
   - 区间里每个数字出现次数 / 奇偶次数
   - 区间有多少个不同的数
   - 区间众数、区间出现次数最多的数
2. **简单贡献类**
   - 区间平方和、区间两数的贡献
   - 区间逆序对数量（离线版）
3. **简单最值 / 特殊条件**

## 二、莫队硬性前提（重要！）

满足这 3 条才能用莫队：

1. **离线**：可以先把所有询问全部读进来，排完序再算
2. **可加减**：能快速实现
   - 给区间加一个数（add）
   - 给区间删一个数（del）
3. （第三条，配合分块排序保证移动复杂度）

## 三、复杂度范围

- `n, q ≤ 2×10^5` 左右
- 纯暴力：`O(nq)` 爆炸超时
- 莫队：`O((n+q)√n)` 稳稳通过

## 四、莫队 不能干什么（避坑）

1. 强制在线的题（必须读一个问一个、不能离线）❌
2. 数组有单点修改 / 区间修改（普通莫队不行，要**带修莫队**）
3. n 开到 10^6 以上：莫队会超时 ❌
