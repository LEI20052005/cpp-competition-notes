# 莫队

> 莫队 = 专门用来处理 大量区间询问 的暴力优化算法

## 一、莫队能干什么（经典题型，全覆盖）

1. **统计类（最常用）**
   - 区间里每个数字出现次数 / 奇偶次数
   - 区间有多少个不同的数
   - 区间众数、区间出现次数最多的数
2. **简单贡献类**
   - 区间平方和、区间两数的贡献
   - 区间逆序对数量（离线版）
3. **简单最值 / 特殊条件**

## 二、莫队硬性前提（重要！）

满足这 3 条才能用莫队：

1. **离线**：可以先把所有询问全部读进来，排完序再算
2. **可加减**：能快速实现
   - 给区间加一个数（add）
   - 给区间删一个数（del）
3. （配合分块排序保证移动复杂度）

## 三、复杂度范围

- `n, q ≤ 2×10^5` 左右
- 纯暴力：`O(nq)` 爆炸超时
- 莫队：`O((n+q)√n)` 稳稳通过

## 四、莫队 不能干什么（避坑）

1. 强制在线的题（必须读一个问一个、不能离线）❌
2. 数组有单点修改 / 区间修改（普通莫队不行，要**带修莫队**）
3. n 开到 10^6 以上：莫队会超时 ❌

## 五、莫队模板

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100010;

// 询问结构体
struct Query
{
    int l, r, id;
} q[N];

int n, m;
int a[N];       // 原数组
int cnt[N * 5]; // 计数数组，开大防止越界
int ans[N];     // 存每个询问答案
int curL, curR; // 当前莫队区间 [curL, curR]
int res;        // 当前区间答案（根据题目改）
int block;      // 块大小

// ============ 核心1：add 加入一个位置 ============
void add(int x)
{
    cnt[a[x]]++;
    // 这里根据题目改逻辑
    // 本题：统计出现奇数次数字个数
    if (cnt[a[x]] % 2 == 1) res++;
    else res--;
}

// ============ 核心2：del 删除一个位置 ============
void del(int x)
{
    // 本题：先判奇偶，再删
    if (cnt[a[x]] % 2 == 1) res--;
    else res++;
    cnt[a[x]]--;
}

// ============ 核心3：莫队排序规则（无lambda，超好懂） ============
bool cmp(Query A, Query B)
{
    // 1. 左端点不在同一块：块号小的放前面
    if (A.l / block != B.l / block)
        return A.l < B.l;

    // 2. 同一块：奇偶优化
    // 奇数块 r降序  偶数块 r升序
    return (A.l / block % 2 == 1) ? (A.r > B.r) : (A.r < B.r);
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;
    block = sqrt(n);   // 块长 = 根号n

    // 读原数组
    for (int i = 1; i <= n; i++)
        cin >> a[i];

    // 读所有询问，记录编号id
    for (int i = 1; i <= m; i++)
    {
        cin >> q[i].l >> q[i].r;
        q[i].id = i;
    }

    // 离线排序
    sort(q + 1, q + m + 1, cmp);

    // 初始化：当前区间为空 [1,0]
    curL = 1, curR = 0;
    res = 0;
    memset(cnt, 0, sizeof cnt);

    // ============ 核心4：移动指针处理所有询问 ============
    for (int i = 1; i <= m; i++)
    {
        int L = q[i].l;
        int R = q[i].r;

        // 四个方向慢慢挪指针
        // 正确顺序必须是：先删右边，再扩右边！
        while (curL > L) add(--curL);
        while (curR < R) add(++curR);
        while (curL < L) del(curL++);
        while (curR > R) del(curR--);

        // 保存当前询问答案
        ans[q[i].id] = res;
    }

    // 按输入顺序输出
    for (int i = 1; i <= m; i++)
    {
        if (ans[i] == 0) cout << "YES\n";
        else cout << "NO\n";
    }

    return 0;
}
```
