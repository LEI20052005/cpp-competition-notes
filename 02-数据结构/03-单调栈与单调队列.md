## 单调栈：柱状图最大矩形（3 个核心要点）

1. **栈的规则**：栈存下标，下标对应高度「单调递增」，遇矮则弹；
2. **结算逻辑**：弹出下标时，用「当前高度 × 左右矮柱间距」计算面积，更新最大值；
3. **收尾技巧**：遍历到 n（虚拟矮柱），强制清空栈，无需额外处理剩余元素。

## 严格递增模板

### 模板1：核心转化（必背）

- **题目要求**：原数组严格递增 `w1 < w2 < w3 ...`
- **强制换元**：`a[i] = w[i] - i`
- **结论（固定死）**：原数组严格递增 ⟺ 新数组 a 非递减
- 只要是「整数严格递增改造题」，全部都用这个转换模板。

### 模板2：最少修改（必背）

给定一段数组，只能改数，求：改成非递减，最少改几个数？

- **万能固定公式**：最少修改数量 = 元素总数 − 最长不下降子序列长度
- **搭配算法**：贪心 + 二分(upper_bound) + vector 求 LIS
- 也是全网通用标准模板。

```cpp
// 示例：upper_bound 求最长不下降子序列（LIS）
vector<int> d;
for (int i = 1; i <= n; i++) {
    auto it = upper_bound(d.begin(), d.end(), a[i]); // 不下降用 upper_bound
    if (it == d.end()) d.push_back(a[i]);
    else *it = a[i];
}
// LIS 长度 = d.size()
```

## 数组去重（unique + erase）

拆成 2 步讲（超简单）：

1. `unique(...)`：把相邻重复元素移到数组末尾，返回第一个重复元素的位置。
   - 注意：**必须先排序**，否则去重无效！
2. `erase(...)`：从 unique 返回的位置开始，一直删到末尾，把所有重复元素删掉。

```cpp
vector<int> tmp = a; // 复制一份高度
tmp.erase(unique(tmp.begin(), tmp.end()), tmp.end());
```

- 输入：`1 2 2 3 3 3` → 输出：`1 2 3`

## 单调队列：滑动窗口最大值模板

```cpp
// 滑动窗口最大值 通用函数
// nums：原数组
                     vector<int> slidingWindowMax(vector<int>& nums, int k)
{
    int n = nums.size();
    vector<int> res;        // 存每个窗口的答案
    deque<int> dq;          // 单调队列：只存【数组下标】
    // 遍历每一个元素，窗口不断右移
    for (int i = 0; i < n; i++)
    {
        // =============================================
        // 步骤1：清理队尾，维持队列【单调递减】
        // 新来的数比队尾大 → 队尾永远不可能是最大值，直接删掉
        // =============================================
        while (!dq.empty() && nums[i] >= nums[dq.back()])
        {
            dq.pop_back();
        }
        // 把当前下标加入队列
        dq.push_back(i);
        // =============================================
        // 步骤2：清理队头，剔除【已经滑出窗口左边界】的元素
        // 窗口左边界 = i - k + 1
        // 下标小于左边界 = 过期无效，踢出
        // =============================================
        while (!dq.empty() && dq.front() < i - k + 1)
        {
            dq.pop_front();
        }
        // =============================================
        // 步骤3：形成完整窗口后，记录答案
        // i >= k-1 代表第一个窗口已经成型
        // 队头 = 当前窗口最大值下标
        // =============================================
        if (i >= k - 1)
        {
            res.push_back(nums[dq.front()]);
        }
    }
    return res;
}
```

## 最少修改次数：LIS 模板

```cpp
// 计算：把一段数组改成【非递减】最少要改多少个数
int cal(int arr[], int len)
{
    // lis 是模拟单调栈，只用来求最长不下降子序列长度
    vector<int> lis;
    // 遍历数组每一个元素
    for (int i = 1; i <= len; i++)
    {
        // 当前数字
        int x = arr[i];
//if(a[j] < a[L] || a[j] > a[R]) continue;（如果右左右边界）
        // ---------------- 核心模板 ----------------
        // upper_bound：找第一个 大于 x 的位置
        // 作用：求【最长不下降子序列】（允许相等）
        auto it = upper_bound(lis.begin(), lis.end(), x);
        if (it == lis.end())
        {
            // 如果 x 比栈顶大/等于 → 直接加在后面
            // 代表：可以继续延长最长合法序列
            lis.push_back(x);
        }
        else
        {
            // 否则：替换掉第一个比 x 大的数
            // 作用：降低后面数字的门槛，让后面能接更多数
            *it = x;
        }
        // ------------------------------------------
    }
    // 最终答案公式：
    // 最少修改数 = 总数字个数 - 最多能保留不动的个数（lis长度）
    return len - lis.size();
}
```

## 单调栈：最大矩形模板

```cpp
// 核心函数：传入一维高度数组，返回柱状图中最大矩形面积
// h: 存储每个柱子的高度（如[2,2,2,5,5,5]）
int largestRectangle(vector<int>& h)
{
    stack<int> st;   // 栈中存储「柱子下标」，而非高度！核心技巧：通过下标反查高度，同时计算宽度
                     // 栈内下标对应的高度，始终保持「单调递增」
    int res = 0;     // 存储全局最大矩形面积，初始为0
    int n = h.size();// 柱子总数（高度数组长度）
    // 遍历所有柱子，注意i要走到n（额外多走一步，模拟末尾高度为0的“虚拟柱子”）
    for (int i = 0; i <= n; i++)
    {
        // 关键：最后i==n时，cur_h设为0（虚拟矮柱），强制清空栈中剩余元素
        // 非最后一步时，cur_h就是当前柱子的高度
        int cur_h = (i == n) ? 0 : h[i];
        // 核心循环：当前高度 < 栈顶下标对应的高度 → 单调递增被破坏，弹栈计算面积
        while (!st.empty() && cur_h < h[st.top()])
        {
            int idx = st.top();  // 取出栈顶下标（对应“被堵死的高墙”）
            st.pop();            // 弹出栈顶（高墙结算完毕，废弃）
            int height = h[idx]; // 高墙的高度（要计算的矩形高度）
            // 计算宽度：核心公式！分两种情况
            // 1. 栈空 → 说明当前高墙是“最左的柱子”，宽度就是i（从0到i的所有列）
            // 2. 栈非空 → 宽度 = 当前下标i - 新栈顶下标 - 1（左右矮柱夹出来的宽度）
            int width = st.empty() ? i : i - st.top() - 1;
            res = max(res, height * width); // 更新全局最大面积
        }
        st.push(i); // 当前下标入栈，维持栈的单调递增性
    }
    return res;     // 返回最大面积
}
```
