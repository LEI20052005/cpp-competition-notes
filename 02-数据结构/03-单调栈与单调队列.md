## 单调栈：柱状图最大矩形（3 个核心要点）

1. **栈的规则**：栈存下标，下标对应高度「单调递增」，遇矮则弹；
2. **结算逻辑**：弹出下标时，用「当前高度 × 左右矮柱间距」计算面积，更新最大值；
3. **收尾技巧**：遍历到 n（虚拟矮柱），强制清空栈，无需额外处理剩余元素。

## 严格递增模板

### 模板1：核心转化（必背）

- **题目要求**：原数组严格递增 `w1 < w2 < w3 ...`
- **强制换元**：`a[i] = w[i] - i`
- **结论（固定死）**：原数组严格递增 ⟺ 新数组 a 非递减
- 只要是「整数严格递增改造题」，全部都用这个转换模板。

### 模板2：最少修改（必背）

给定一段数组，只能改数，求：改成非递减，最少改几个数？

- **万能固定公式**：最少修改数量 = 元素总数 − 最长不下降子序列长度
- **搭配算法**：贪心 + 二分(upper_bound) + vector 求 LIS
- 也是全网通用标准模板。

```cpp
// 示例：upper_bound 求最长不下降子序列（LIS）
vector<int> d;
for (int i = 1; i <= n; i++) {
    auto it = upper_bound(d.begin(), d.end(), a[i]); // 不下降用 upper_bound
    if (it == d.end()) d.push_back(a[i]);
    else *it = a[i];
}
// LIS 长度 = d.size()
```

## 数组去重（unique + erase）

拆成 2 步讲（超简单）：

1. `unique(...)`：把相邻重复元素移到数组末尾，返回第一个重复元素的位置。
   - 注意：**必须先排序**，否则去重无效！
2. `erase(...)`：从 unique 返回的位置开始，一直删到末尾，把所有重复元素删掉。

```cpp
vector<int> tmp = a; // 复制一份高度
tmp.erase(unique(tmp.begin(), tmp.end()), tmp.end());
```

- 输入：`1 2 2 3 3 3` → 输出：`1 2 3`
